# Spend Your Heartbeats

花掉一生心跳 —— 一个用真实年龄计算剩余心跳，再用生活事件去消耗它们的交互式网页。

输入年龄，按静息心率与预期寿命估算你剩余的心跳总数，然后点“吃个苹果”“熬一整夜”“买房 + 30 年房贷”这些项目，看着数字一点点蒸发。

**在线体验：** https://你的用户名.github.io/你的仓库名/

---

## 这个页面在做什么

1. 选择你的年龄。
2. 按 **72 次/分** 静息心率、**78 岁** 预期寿命，估算剩余心跳总数。
3. 从“日常 / 冒险 / 人生 / 命运”四组项目里点击消耗，余额实时减少，心电图同步反应。

年龄越大，余额越少。点“买房 + 30 年房贷”这种命运级项目，数字会成亿地掉。

---

## 功能

- 年龄滑块，实时计算剩余心跳
- 消耗项目分四组，从 200 次（打个喷嚏）到 14.4 亿次（买房 + 30 年房贷）
- 心电图随余额和点击实时变化：余额越少波形越平缓，点击时短暂应激飙升
- 命运级项目带闪白、脉冲光晕和更慢的数字滚动
- 余额不足时消耗量变红
- 余额归零后页面降低饱和度，提示“心跳耗尽”
- 纯静态单文件，无后端、无外部依赖

---

## 消耗项目怎么定的

| 分组 | 示例 | 消耗量 |
|------|------|--------|
| 日常 | 打个喷嚏 / 吃个苹果 / 精心化个全妆 | 200 / 5,000 / 6,000 |
| 日常 | 看一次电影 / 刷一晚上视频 / 回家吃年夜饭 | 15,000 / 40,000 / 60,000 |
| 冒险 | 看一部恐怖片 / 熬一整夜 / 跑一次马拉松 | 80 万 / 250 万 / 400 万 |
| 人生 | 连续加班一周 / 考研一年 / 上高中三年 | 2,000 万 / 1.2 亿 / 3 亿 |
| 命运 | 结一次婚 / 养一个孩子到 18 岁 / 买房 + 30 年房贷 | 1.5 亿 / 6.8 亿 / 14.4 亿 |

消耗量按时间折算并略作情绪加权，不是精确医学数据，只为了让“心跳被花掉”这件事有体感。
